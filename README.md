# sistema-de-pedidos-online
This project is a web sistem to create and manage online orders, develop with React e node.js.

# How to use the program
## Frontend
1. Open the terminal
2. cd frontend
3. npm install
4. npm run dev
5. The front is running

## Backend
1. Open the terminal
2. cd backend
3. npm install
4. cd src
5. node index.js

## Data Base
1. Open the terminal
2. cd backend
3. cd prisma
4. npx prisma studio
